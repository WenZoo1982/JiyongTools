# 即用工具箱（JiyongTools）

集成常用系统与开发辅助工具，让日常操作更简单高效。

即用工具箱是一款面向 Windows 用户的轻量级桌面工具软件，将日常使用的系统信息查询、开发辅助和快捷启动功能整合在一个简洁的界面中。

## 主要功能

- **窗口信息**：获取目标窗口的标题、句柄、进程信息、窗口类名及位置尺寸等信息。
- **进制转换**：支持十进制与十六进制之间的快速转换。
- **进程信息**：查询进程名称、PID、进程路径、主窗口信息、启动时间及资源占用等。
- **工具收藏**：收藏常用的本地程序，支持分类管理与快速启动。
- **系统托盘**：支持最小化到系统托盘，方便随时唤出。
- **开机自启动**：支持设置开机自动启动。
- **主题设置**：支持浅色、深色及跟随系统主题。
- **数据管理**：支持工具收藏数据导入与导出。

## 系统要求

- 操作系统：Windows 10 / Windows 11
- 系统架构：64 位（x64）
- 运行环境：无需单独安装 .NET Runtime。
